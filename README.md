# Excel Formula Fusion — Smart Dynamic V1.3

Streamlit app for generating formula-based Excel outputs while preserving workbook structure.

## Fixes in V1.3

- Rebuilt UI to high-contrast light theme.
- Fixed invisible JSON upload / file uploader text.
- Fixed invisible selectbox and text input values.
- Made auto-detected defaults visible as a clear table.
- Added current mapping summary in the main page before export.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

Upload these files to GitHub root and set main file path to:

```text
app.py
```
